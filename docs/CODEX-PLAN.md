## Этап Д1 — узкий headless-срез контракта (выполнен, первый код)

**Статус:** выполнен узкий срез; фактические тесты, пропуск и ограничения приведены в [отчёте Д1](design/headless-d1.md). Q17 уточнён, но не закрыт. Постановка: исполнить основные гарантии [контракта Д0](design/application-api-contract.md) на двух разнородных модулях **без GUI и без физической симуляции**; выявленные изменения документа фиксировать вместе с проверками.

**Что сделать:**
- Минимальный чистый Python-пакет, доступный через импорт и JSON CLI с одинаковым поведением.
- Только нужный срез: диспетчер запросов/ответов, каталог двух модулей, сеанс и монотонная ревизия, команды, диагностики, ссылки на локальную справку, сериализация, безопасная запись/чтение JSON, восстановление.
- Два примера: (а) условный учебный сценарий теплообменника с конфигурацией, неизменяемым снимком и **тестовыми данными, явно помеченными как фикстура, а не рассчитанные показания**; (б) качественный выбор области/точки влажного воздуха без психрометрических свойств. Отказ запросов неподтверждённых модельных показаний обязателен.
- `pytest` проверяет атомарный отказ, конфликт ревизий, сохранность старого снимка, JSON round-trip обоих модулей, отказ записи с сохранением прежнего файла, отсутствие NaN/Infinity и недопустимой физики, паритет Python/CLI и отсутствие утечек скрытого эталона (если механизм проверки ответа входит в срез).
- Сохранения вне EXE, безопасный временный файл с последующей атомарной заменой; доступ к произвольному пути через CLI не делать по умолчанию. Неотработанные вопросы безопасности/совместимости пометить явно.

**Что не делать:** pywebview/HTML/JS, реальные теплофизические и психрометрические модели, насосы или полноценные лабораторные, графики, систему плагинов, сетевой сервер, БД и сложную общую абстракцию. Не считать выполненными M01–M10, если реально реализована только их часть.

**Критерий:** два headless-сценария действительно проходят в Python и JSON CLI, тесты запущены и результаты приведены; выявленные несоответствия Д0 отражены в документах, Q17 оценивается на основании фактического выполнения. Это **не** научная валидация теплообменника или готовое приложение.

## Этап Д2а — самостоятельные ответы, контекст проверки и политика показа (следующее задание Codex)

**Статус:** требуется реализация в существующем Python-ядре, без GUI. Опора: [фактический Д1](design/headless-d1.md), [контракт Д0](design/application-api-contract.md) и [методические правила](design/methodical-interaction.md).

**Цель:** добавить минимальные `answer.put` и `answer.check` в уже работающий API/CLI, не смешивая состояние ответа с происхождением данных и не создавая оценочную систему. Привязка к `snapshot_id`/версии, черновик, правило согласованности и возвращаемый статус проверки (`matches`, `does_not_match`, `not_checked`). Только **отдельное разрешённое тестовое задание** с фиксированным эталоном и допуском, явно отличное от открытой демонстрации R04. Для иных заданий без утверждённой проверки возвращать `not_checked` без выдуманных допусков.

**Политика доступа:** определить, через какие обычные операции студент видит ответ и справку, а через какие проверяет свою попытку. Не раскрывать эталон в публичной выдаче, сохранениях, диагностике, справке и JSON CLI до разрешённого действия. При этом зафиксировать ограничение: полностью офлайн-приложение с локальным кодом/данными **не обеспечивает криптографической секретности** эталонов от пользователя с доступом к файлам и отладке; это защита учебного сценария от случайного преждевременного раскрытия, не противодействие взлому.

**Проверки:** Python/JSON CLI, совпадение/несовпадение/непроверено, единицы, привязка к старому снимку при изменении условий, конфликт ревизий, отсутствие изменения при отказе, round-trip ответов и отсутствие случайного раскрытия эталона. Уточнить `show_fixture` как чтение либо явно документировать мутацию; согласовать `session.actions` с фактической доступностью команды. Предпочитать небольшие изменения и тесты, не широкую переработку.

**Выход:** код, работающие `pytest`, README и короткий отчёт; обновление Q09/Q17 по подтверждённым гарантиям. Не объявлять утверждёнными правила конкретного преподавателя и не реализовывать физику.
