# План динамического исследования Lab_FP в изолированной Windows VM

План подготовлен по [статическому анализу](Lab_FP_analysis.md), [сценарию и состояниям](Lab_FP_workflow.md) и [реестру вычислений](Lab_FP_calculations.md). Программа в этом исследовании не запускалась. Цель — проверить последствия исполнения, доступность и жизненный цикл объектов, а не заново доказывать арифметические операции, уже читаемые в P-code.

## Подготовка и общие правила фиксации

Изолированная Windows VM без сети и общих папок с основной системой, с чистым снимком до каждого независимого сценария. Передать внутрь только контролируемую копию файла; зафиксировать хеш, версию Windows и масштаб/частоту экрана, системное время и конфигурацию среды. Не подключать интернет и не запускать в основной ОС. До и после отдельных опытов сравнивать список файлов и SharedObject/пользовательских каталогов внутри VM; если доступно, отдельно фиксировать обращения к файлам средствами самой VM. Не интерпретировать отсутствие найденных файлов как абсолютное доказательство отсутствия любой записи.

Для каждого сценария сохранять видеозапись или последовательность скриншотов с метками времени, введённые значения, видимые показания, режим, состояния кнопок и окон, длительности и фактические файлы; отдельно записывать расхождения с ожидаемым. Возвращать чистый снимок перед сравнительными сериями. Запуск в рамках текущего задания не выполняется.

## Критерии завершения исследования в VM

Каждый выполненный сценарий должен иметь дату, версию среды, исходный снимок, результат и ссылки на локальные свидетельства; несделанные сценарии остаются открытыми. Отдельно фиксировать, подтверждена ли динамическая гипотеза и что остаётся неоднозначным. Наблюдаемая анимация не подтверждает математическую физическую модель. Научную применимость зависимостей и происхождение коэффициентов необходимо устанавливать по методическим и независимым источникам, а не по совпадению с работой Flash.
