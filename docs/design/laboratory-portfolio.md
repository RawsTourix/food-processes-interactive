## Для каждой лабораторной проверить пять независимых аспектов

| Критерий | Вопрос | Статус и доказательство |
|---|---|---|
| M — методика | Есть ли читаемая методичка с учебной целью, порядком действий, протоколом и перечнем расчётов? | Источник/страницы/недостающие разделы |
| P — физика | Есть ли физическая постановка, корректная область и обоснованные параметры? | Формулы, допущения, диапазоны, происхождение |
| V — верификация/валидация | Проверены ли уравнения независимым способом, сравнение с данными реальной установки (если речь о реальной)? | Отдельные статусы математической верификации и экспериментальной валидации |
| I — интерактивность | Есть ли содержательная связь действий и показаний/диаграммы, самостоятельная работа и подсказки? | Краткий учебный сценарий и необходимые типы визуализаций |
| S — возможность разработки | Реализуем ли минимальный проверяемый модуль без неподтверждённых чисел и слишком сложных зависимостей? | Минимальный объём, блокеры и варианты упрощения |

Каждую категорию отмечать **подтверждено / частично / не исследовано / блокировано** с основанием. Не выводить итоговый зелёный статус из одной доступной методички или корректности арифметики.

## Приоритет и очередность

1. **Теплообменник** — первый вертикальный срез (есть глубокая база, но научные блокеры для реального стенда).
2. **Влажный воздух** — хороший кандидат для ранней проверки иного типа интерактивности (диаграммы), **не утверждён вторым модулем** до аудита.
3. **Гидродинамика** — кандидат для следующего полноценного стенда при подтверждении реальной методики и модели.
4. **Центрифугирование / фильтр-пресс / барабанная сушилка** — выбор по доступным источникам и учебной отдаче после краткого аудита.
5. **Выпаривание и ректификация** — оставить в портфеле, но детальную модель не начинать без проверенных исходных данных.

Приоритет не равен предполагаемому «уровню сложности» и может измениться по результатам инвентаризации. Нет обязательства делать восемь симуляторов; разные виды интерактивных учебных инструментов методически равноправны.

## Следующее действие Codex — короткий сравнительный аудит (аналитика без кода)

Для каждого кандидата: найти локальную методику/протокол, если доступны; определить ожидаемый ввод/вывод, тип интерактивности, требуемые формулы, модель и неизвестные; дать 1–2 предложения по минимальному учебному сценарию. Приводить ссылки на локальные файлы/страницы **без публикации оригиналов**.

Не повторять углублённый аудит теплообменника. При отсутствии доступа к конкретному локальному материалу зафиксировать недоступность, а не объявлять материал отсутствующим.

**Результат аудита:** обновлённый портфель с доказательствами и обоснованием выбора второго *отличающегося* учебного инструмента; без создания восьми отдельных ТЗ или реализации симуляторов.
