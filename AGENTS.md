# Codex instructions

Проект Food Processes Interactive. Язык документации, интерфейса и пользовательских ошибок — **русский**. Комментарии и имена Python API можно писать на английском.

1. **Сначала методика.** Не реализуй формулу, параметры установки или показания датчиков без документированного источника и проверки условий применения. Для спорных утверждений сохраняй ссылку на документ/страницу и пометку «не подтверждено».
2. **Сначала API.** Любое лабораторное действие должно быть доступно из чистого Python без GUI; предусмотри JSON CLI и pytest. Интерфейс не должен содержать самостоятельной предметной модели.
3. **Не выдумывай физику.** Не подменяй неизвестную динамику или измерения декоративной анимацией, выдавая её за расчёт. Вместо `NaN` выдавай диагностическое сообщение.
4. **Единые данные.** Материалы и формулы имеют стабильные ID, используются в лабораторных и справочнике без копирования.
5. **Реальные проверки.** Документируй тестируемые сценарии, независимые числовые эталоны, результаты запуска и нерешённые вопросы. Не называй тест пройденным, если не запускал его.
6. **Минимальный стек.** Python + pywebview + HTML/CSS/SVG + минимум JavaScript, Windows x64, один EXE. Избегай больших зависимостей и серверных систем без согласованной причины.
7. **Сохранение.** Введённые значения и протоколы не теряются при закрытии окна/перезапуске. Сохраняй пользовательские данные вне EXE, предусмотрев версионирование и экспорт/импорт.
8. **Безопасность и права.** Не запускай неизвестные EXE вне изолированной среды. Не публикуй оригинальный Flash EXE, чужие методические PDF или извлечённые ресурсы в публичном репозитории без проверки прав.
9. **Объём изменений.** Одна задача — один проверяемый результат. На этапе аудита не делай реализацию и не переходи к следующей фазе самовольно.
10. **Локальные первоисточники.** Оригинальный EXE и методические файлы хранятся на ноутбуке, а не в GitHub. При аудите проверяй, что локальные пути реально доступны; если нет — честно фиксируй блокировку, не имитируй изучение источника. Не добавляй такие файлы в коммиты, не открывай их через корень локального HTTP сервера.
11. **Локальная графика.** pywebview может запускать локальный HTTP только для статики интерфейса; он работает без интернета. Для команд используй Python–JS мост, а не новый REST-сервис без необходимости. Проверяй прослушиваемый адрес и не допускай доступа к локальным источникам.
12. **Приоритет UX.** Понятные русские подсказки, согласованные состояния, контекстная методическая помощь. Избегай перегруженности функциями.
13. **Проектирование после аудита.** До утверждения научной модели не выдавай температуры и результаты опыта, полученные по кадрам/эмпирическим коэффициентам Flash, за физически достоверные. Изучай новые вопросы точечно; решения и доказательства фиксируй в реестре. Не возобновляй полный статический аудит без отдельного основания.
